Habit Tracker - deploy on GitHub Pages
1. Create a new PUBLIC repo on github.com (e.g. habit-tracker).
2. Upload ALL files from this folder to the repo root (Add file > Upload files).
3. Repo Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. After ~1 minute open https://YOUR-USERNAME.github.io/habit-tracker/ on your phone.
5. Android Chrome: menu > Install app. iPhone Safari: Share > Add to Home Screen.
